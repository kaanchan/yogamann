# yogamann
Image to mannequin generator — converts yoga pose photos into wooden artist mannequin renders using ControlNet + Stable Diffusion.

## Quick start

```bash
conda activate yogamann          # or your env name
cd yogamann
```

## Single image

```bash
python src/make_mannequin.py input/yoga-pose-sample-1.webp --profile yoga_asana
```

Output lands in `out/` as:
- `yoga-pose-sample-1--v1.png` — mannequin render
- `yoga-pose-sample-1--v1-comparison_2.png` — vertical stack (original / mannequin)
- `yoga-pose-sample-1--v1-comparison_4.png` — 2×2 grid (original / controlnet / mannequin / depth)

## Batch — whole folder

```bash
python src/make_mannequin.py --folder input --profile yoga_asana_batch_1
```

Processes every `.jpg / .jpeg / .png / .webp` file in `input/` and generates multiple variants per image according to the profile.

## Browse results in the browser

After any run:

```bash
python src/make_gallery.py          # reads out/ → writes out/index.html
```

Open `out/index.html` directly in Chrome / Firefox / Edge (no server needed). Click any card to enlarge.

## Profiles

Profiles live in `profiles/` (YAML). Pass by name (no extension) or full path.

| Key | Type | Default | Description |
|-----|------|---------|-------------|
| `versions` | int | 1 | Variants to generate per image |
| `random` | bool | false | `true` = sample ranges randomly; `false` = linear sweep |
| `steps` | int or `[lo, hi]` | 40 | Diffusion steps |
| `cond_scale` | float or `[lo, hi]` | 1.0 | ControlNet conditioning strength |
| `guidance` | float or `[lo, hi]` | 7.5 | CFG guidance scale |
| `seed` | int or `[lo, hi]` or null | null | null = random each run |
| `sheet_scale` | float | 1.0 | Scale factor for comparison sheets (0.5 = half size) |
| `prompt` | string | wooden artist mannequin… | Positive prompt |
| `neg_prompt` | string | null | Negative prompt |

### Example profile (parameter sweep)

```yaml
versions: 3
random: false           # linear interpolation across ranges
steps: 30
cond_scale: [1.0, 1.6]  # produces 1.0, 1.3, 1.6
guidance:  [5.5, 7.5]   # produces 5.5, 6.5, 7.5
seed: 123               # fixed so only numeric knobs vary
prompt: wooden mannequin, warrior II yoga pose, studio grey backdrop
```

## Inspect the worklist without running

```bash
python src/make_mannequin.py --folder input --profile yoga_asana_batch_1 \
  --dump-worklist worklist.json --dump-only
```

Writes a JSON file of all planned tasks so you can review before committing GPU time.

## Run from a saved worklist

```bash
python src/sd_make.py --from-worklist worklist.json
```

## Output folder layout

```
out/
  <stem>--v1.png                    mannequin render
  <stem>--v1-comparison_2.png       vertical stack  (original / mannequin)
  <stem>--v1-comparison_4.png       2×2 grid        (original / controlnet / mannequin / depth)
  <stem>-controlnet.png             OpenPose skeleton used as control image
  <stem>-controlnet.json            MediaPipe keypoints (when available)
  index.html                        gallery (generated by make_gallery.py)
```
